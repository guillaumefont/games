# Scanned materials

All files here are from Poly Haven (https://polyhaven.com), licence CC0 1.0 (public domain),
downloaded at 1k:

- Each material has Diffuse, nor_gl (normal) and arm (occlusion, roughness, metal). Per world
  (loose ground, bare rock, cliff face), see `LOOKS` in scripts/vgame.gd: aerial_ground_rock,
  marble_cliff_03, cliff_side, snow_field_aerial, marble_cliff_01, aerial_grass_rock, mossy_rock,
  rock_face_03, aerial_asphalt_01, dark_rock_02, hangar_concrete_floor, concrete_panels,
  burned_ground_01, dark_rock; metal_plate_02 also skins hulls and structures
- sky.hdr: kloofendal_48d_partly_cloudy_puresky, used for reflections only
- hull_Diffuse.jpg: metal_plate_02 Diffuse lightened and mostly desaturated (airframe grey)
